同一物种的气相和液相不可混用。此处为实测/评审热化学数据，并非 Materials Project DFT 形成能。

02
S–Cl 键能：参考态与推导

双原子气相分子 SCl 的 298.15 K 键解离反应为：

SCl(g) → S(g) + Cl(g)
ΔH° = 277.17 + 121.301 − 156.46 = 242.01 kJ/mol

数据分别来自 S(g)、Cl(g) 的 CODATA 标准生成焓，以及 SCl(g) 的 NIST/JANAF 标准生成焓。由于此处使用 298.15 K 热力学数据，严格说是298 K 键解离焓，并非 0 K 的 D₀。

S(g): +277.17 kJ/molCl(g): +121.301 kJ/molSCl(g): +156.46 kJ/mol
不能把 242.0 kJ/mol 直接视作 SCl₂、S₂Cl₂、SCl₄ 中任意一根 S–Cl 键的解离能；键的强度取决于价态、分子结构、断裂方式及相态。
03
SCl₄：为什么暂不填写形成焓

经检索，没有找到可核实的、与上表相同基准的 SCl₄ 标准生成焓数据。

SCl₄ ⇌ SCl₂ + Cl₂

已发表的结构与反应研究指出：SCl₄ 在约 −78 °C 可由 SCl₂ 与 Cl₂ 反应制得；低于约 −30 °C 的固相被报道为 [SCl₃]⁺[Cl]⁻ 型，高于其熔化/分解温度会回到 SCl₂ 与 Cl₂。

因此，SCl₄(g)、分子态 SCl₄ 和低温离子固相不应共用一个未经定义的“形成能”。未来若有量化计算或可靠热化学数据，可按具体参考态补充。

分子结构与名义氧化态
S₂Cl₂
Cl—S—S—Cl
平均 S(+I)，分子含 S–S 键；不能用孤立 S–Cl 键能代表整个分子的稳定性。
SCl₂
Cl—S—Cl
S(+II)，分子为弯曲型；可与 S₂Cl₂/Cl₂ 化学环境发生转化。
SCl₄
[SCl₃]⁺ · [Cl]⁻
形式 S(+IV)；给出的是已报道低温固相的离子性描述，而非室温稳定游离 SCl₄ 分子。

与 NFSC 的关系：上述物种可作为高压氧化机制的候选结构模型，但热化学生成焓或形式氧化态本身不能证明电极内部存在 S–Cl 键或某种具体硫氯化合物。需要联用 S K-edge XANES、Cl K-edge/XPS、Raman，以及充放电终态的结构表征验证。

原始出处与数据定义
  1. NIST Chemistry WebBook — SCl₂, CAS 10545-99-0：ΔfH°(g) = −17.57；ΔfH°(l) = −49.79 kJ/mol。
  2. NIST Chemistry WebBook — S₂Cl₂, CAS 10025-67-9：ΔfH°(g) = −16.74；ΔfH°(l) = −58.16 kJ/mol。
  3. NIST CCCBDB — SCl radical：ΔfH°(g, 298 K) = +156.46 kJ/mol（JANAF）。
  4. NIST WebBook — atomic sulfur：ΔfH°(g) = +277.17 kJ/mol（CODATA）。
  5. NIST WebBook — atomic chlorine：ΔfH°(g) = +121.301 kJ/mol（CODATA）。
  6. Voßnacker et al., Angew. Chem. Int. Ed. (2022)：硫氯化合物稳定性与低温 SCl₄ 离子型结构的文献依据。

来源主要为 NIST-JANAF 第四版 / NIST WebBook 所收录的已评审热化学数据；展示日期：2026-10-09。标准生成焓 ΔfH° 与 DFT 0 K 形成能 ΔEform、标准 Gibbs 生成自由能 ΔfG° 不是同一个量。
