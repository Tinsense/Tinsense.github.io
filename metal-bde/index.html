M–S / M–Cl 二维图 + Li₂S / Na₂S 反应可能性热力图

在之前二维分区图的基础上，新增了一个热力图，用键能描述符来可视化各个金属氯化物与 Li₂S / Na₂S 发生 A₂S + MClₓ → ACl + MS 类交换反应的“相对可能性”。
热力图评分定义：
SLi(M) = [D(M–S)-D(M–Cl)] + 156.5
SNa(M) = [D(M–S)-D(M–Cl)] + 164.9
其中 156.5 来自实验 Li–Cl 与 Li–S 的差值，164.9 来自补齐数据库下 Na–Cl 与 Na–S 的差值。
分数越大，越倾向发生 LiCl/NaCl + MS 形成。 这是第一层筛选 descriptor，不等同于严格反应 ΔG。
